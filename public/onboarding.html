Wallet-only onboarding

Your wallet stays yours.

Connect a supported Solana wallet, sign a one-time AETHER login message, and create or access your account. The signature proves wallet ownership only; it does not authorize a trade, transfer, token approval, or custody.

Connect and verify

AETHER never asks for a password, seed phrase, recovery phrase, or private key. Login uses a short-lived server challenge and an explicit message signature.

Status: not connected.
Security rule: the login message explicitly states that it is not a blockchain transaction and does not authorize movement of funds. The authenticated session is stored in a secure HttpOnly cookie, not in browser localStorage.
