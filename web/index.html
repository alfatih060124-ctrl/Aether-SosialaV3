The Aether Standard

Not just who made money. Whether the result is worth following.

AETHER separates trader performance from copy quality so users can evaluate return, risk, liquidity, and execution as different dimensions.

01 — PROOF

Verifiable performance

Performance should be backed by auditable transaction history and reproducible calculations instead of screenshots or isolated claims.

02 — RISK

Risk before return

Drawdown, concentration, liquidity exposure, and downside behavior belong beside ROI — not hidden behind it.

03 — EXECUTION

Follower outcome matters

A high-performing trader can still be a poor copy candidate. AETHER is built to measure execution gap and replication quality.
